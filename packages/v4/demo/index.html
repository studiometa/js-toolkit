Slider

CSS scroll-snap does the scrolling. Slider provides an owner surface — { state, goTo, goToItem } — through provide/inject; SliderCount subscribes to state and each slide calls goToItem() on click through $injectSync , so a control drives its coordinator with no $closest , no handshake and no connectChildren . Buttons emit a bubbling slide event caught by delegation. Add a slide from the console: document.querySelector('[data-ref=wrapper]').insertAdjacentHTML('beforeend', '<div data-component=SliderItem>new</div>') — the count follows.

Mount strategies — data-mount

The registry decides when each instance mounts. Reveal declares mountStrategy: 'in-view' in its config, so every pass through the viewport is a full mount/destroy cycle and the mounted() cleanup runs each time — watch the counters as you scroll. The last box overrides the component default with data-mount="visible" : it mounts once, on first sight, and stays mounted.
